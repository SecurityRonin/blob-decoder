# Privacy Policy

**Effective date:** 2026-07-11
**Product:** blob-decoder CLI / library
**Operator:** Security Ronin Ltd

---

## What blob-decoder collects

Nothing. `blob-decoder` is a local command-line tool and Rust library. It has no
server, no backend, and makes **no network connections of any kind**. It does not
transmit data to Security Ronin or any third party.

## Input data

`blob-decoder` reads the bytes you pass on the command line, via stdin, or from a
file you name, identifies and decodes them in memory, and prints the result. It
does not upload any content, and it writes nothing to disk of its own accord.

## Telemetry

`blob-decoder` has no telemetry, no crash reporting, no analytics, and no update
checks. It never phones home.

## Open source

`blob-decoder` is fully open source under the Apache-2.0 licence. You can audit
every line — including the (empty) set of network calls — at
[github.com/SecurityRonin/blob-decoder](https://github.com/SecurityRonin/blob-decoder).

## Changes

If this policy changes materially, the effective date above will be updated and a
note will appear in the release changelog.
